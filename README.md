# 아파트 값 분리 수거

가격이 공개된 앵커 두 장을 기준으로 새 카드의 자리를 **BELOW / IN / ABOVE**에서 고르는 1인 학습 게임입니다.
연습은 선택, 본게임 10판·100점, 시간 제한 없이 즐길 수 있습니다.
[게임·데이터 안내](./about.html)에서 가격 기준과 기록 저장 방식을 확인하세요.

## GitHub Pages에 올리기

1. 이 `release/`의 **내용물 전부**를 별도의 공개 저장소 루트에 복사합니다. `release` 폴더째 올리지 말고 `index.html`이 저장소 루트에 오게 하세요. 숨김 파일 `.nojekyll`도 포함합니다.
2. 저장소 **Settings → Pages → Source: Deploy from a branch**에서 올린 브랜치(예: `main`)와 **/(root)**를 선택하고 저장합니다.
3. GitHub Pages가 표시하는 주소에서 게임과 안내 페이지를 확인합니다. 모든 실행 자산은 상대 경로이며 프로젝트 하위 경로를 지원합니다.

[GitHub Pages 공식 설정 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

별도 서버 코드, API 키, npm 설치나 Actions 워크플로는 필요하지 않습니다.
원래 분석 프로젝트의 저장소나 Git 이력은 포함하지 말고, 이 묶음만 복사하세요.

현재 공유 링크 `https://nobot-kang.github.io/apt-bin/`은 **사용자가 지정한 샘플 주소**입니다. 배포 완료를 의미하지 않습니다.
실제 주소가 다르면 `records.mjs`의 `GAME_URL`을 바꾸세요. 다운로드 이미지와 복사 문구가 모두 이 주소를 사용합니다.

## 로컬 미리보기

이 묶음이 들어 있는 폴더에서 Python 3로 실행합니다.

```sh
python3 -m http.server 9035 --bind 127.0.0.1
```

`http://127.0.0.1:9035/`를 열어 확인합니다. `file://` 직접 실행은 지원하지 않습니다. Python은 로컬 확인 도구이며 배포 서버에 필요하지 않습니다.

## 데이터와 기록

공개 묶음에는 177개 선정 단지의 게임용 속성·추정가격, 144개 문항, 해당 카드 이미지와 마스코트가 들어 있습니다.
가격은 2026-01-01 기준 매매 모델 추정값이고, 금액 비교는 정확한 만원 단위로 수행합니다. 원본 거래·분석 DB·모델·내부 식별자는 포함하지 않습니다.
정적 파일에는 정답 계산용 가격이 들어 있으므로 개인 학습용 기록이지 서버가 인증한 대회 성적은 아닙니다.

최대 100개의 점수·초 단위 시간·설정·답안 기록은 브라우저에만 저장됩니다. 브라우저 데이터 삭제 시 사라지며 도메인·기기 사이에 자동 이전되지 않습니다.
기록 이미지 다운로드와 링크 문구 복사는 사용자가 버튼을 눌렀을 때만 이루어집니다.

`release-manifest.json`은 현재 공개 파일의 목록·크기·SHA-256입니다. 업데이트는 새 묶음으로 교체하고, 새 목록에 없는 이전 게임 파일은 제거하세요.
